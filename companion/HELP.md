## Overlays.Uno Control

Allows you to control an overlay from [Overlays.uno](http://overlays.uno).

### Configuration

- Open the overlay you want to control in your browser and select "Copy UNO Token"
- Paste the token in the configuration and click "Save"

The connection will then automatically build presets based on the current overlay, allowing you to setup your controls with a drag and drop!

Need to control additional overlays? Simply add an additional connection for that overlay, repeating the steps above.
